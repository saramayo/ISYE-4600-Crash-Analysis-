# ISYE-4600 — AV Crash Severity Prediction

**ISYE 4600 Spring 2026** | Predicting crash severity in NHTSA SGO autonomous-vehicle incident reports.

---

## Quick start

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt

# macOS only — required for XGBoost
brew install libomp

.venv/bin/python scripts/01_clean_incidents.py
.venv/bin/python scripts/02_run_baselines.py
.venv/bin/python scripts/05_stratified_models_ads_l2.py
```

All scripts read/write relative to the project root. Run from any directory as long as you invoke by path.

## Key results

| Model | Precision | Recall | F1 | AUC | FN-rate |
|---|---|---|---|---|---|
| **XGB — ADS** | **0.831** | **0.922** | **0.874** | **0.921** | **6.7%** |
| LR — ADS | 0.499 | 0.845 | 0.627 | 0.531 | 15.5% |
| LR — L2 | 0.985 | 0.967 | 0.976 | 0.876 | 3.3% |
| RF — L2 | 0.972 | 1.000 | 0.986 | 0.836 | 0.0% |

XGBoost is the best ADS model. LR or RF both work for L2 (>97% severe rate makes it near-degenerate).

The pooled LR (single model on ADS+L2 combined) predicted **zero** severe ADS crashes on the test set (100% FN rate), because it learned ADS crashes are "usually not severe" from training data — then the test distribution shifted (+21 pp severe rate). Stratified models per automation level fix this entirely.

## Why stratified models?

ADS crashes have a severe rate of 26% in training but 47% in test (temporal shift). L2 crashes are 98% severe in both. A pooled model learns the level as a proxy for severity and fails completely on ADS test data. Training separate models per automation level removes this shortcut. See `Modeling/MODEL_ANALYSIS.md` for the full technical rationale.

## ADS crash clusters (from `10_cluster_profiling.py`)

K-means (k=7, silhouette-selected) on ADS narrative + tabular features:

| Cluster | Size | Severe rate | Scenario label |
|---|---|---|---|
| C2 | 56% | 26% | Typical street crash (AV stopped) |
| C5 | 21% | **48%** | AV moving at impact |
| C0 | 14% | 33% | Other vehicle struck AV |
| C1 | 4% | 42% | AV hit fixed object (parking lot) |
| C3 | 4% | 31% | AV struck other party |
| C4 | 1% | 0% | Animal strike |

C5 (AV moving, struck by other) is the highest-severity cluster and the primary false-negative risk.
